# RFC: M4.1 bounded single-agent builder

## Decision

M4.1 adds one provider-neutral, tool-using builder beside the preserved M1–M3.5
compiler-era paths. It operates on a copied candidate workspace, not the seed,
and receives a source-free initial orientation plus a M4.0 builder requirement
view. It may inspect, plan, edit, diff, and optionally ask for local verifier
feedback. A separate final local verifier always runs after the candidate delta
is frozen.

`locally_eligible` means that final static/semantic gate passed. It is not
`verified`, not Studio-verified, and not a full product/runtime claim. M4.1
always records `studio: not_run`.

## Boundary

`agent-runtime` owns generic runtime contracts, workspace capability policy,
tool hosting, configuration identity, persistence, and orchestration. It has
no Claude SDK dependency. `agent-claude` is one replaceable adapter using the
official SDK through a Forge-owned in-process MCP server; it exposes no native
filesystem, shell, plugin, skill, subagent, settings, or session persistence
surface.

Generic packages must not import historical mechanic adapters, example
fixtures, benchmark implementations, repair solutions, PatchSet machinery, or
Studio harness registries. This is a structural dependency rule, not a lexical
ban on ordinary game words.

## Evidence identity

`HarnessConfiguration` is deterministically serialized and hashed from the
system prompt, tool schemas/descriptions, capability policy, orientation policy
and hash, resolved requirement-view hash, budget policy, adapter version, and
model configuration. Tool descriptions are versioned harness behavior.

The private, mode-0600 `AgentRun` records tool calls/results, BuildPlan
revisions, usage, budget consumption/exhaustion, WorkspaceDelta, configuration
identity, final verifier reference, and terminal classification. The public
BuildTrace contains only hashes/references and normalized issue summaries.

## Initial experiment

The canonical task copies the vulnerable Collect fixture into a candidate
workspace. Its RequirementSet is external to that fixture and separates a
creator outcome and builder-visible server-authority policy from hidden
evaluator/oracle sentinels. No hidden assertion body, value, grader source, or
fixture implementation detail enters the builder orientation or tool output.

Initial budgets are conservative experimental caps, not optimized thresholds.
Their full configuration, use, and exhaustion are retained for later controlled
experiments. M4.1 stops after exactly one reviewed real AgentRun; a failure is
preserved and classified, never tuned or retried within this milestone.
