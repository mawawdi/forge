# Status Beacon Studio seed

This is only a reproducible place seed for the first prompt-only creator session. Build it once, open the resulting place in Studio, and then disconnect it from Rojo: Studio is the writer for this workflow.

The live product consumes the Studio snapshot and one creator prompt. It does not consume a task package, requirement JSON, evaluator JSON, acceptance JSON, or a prepared solution.

Suggested first prompt:

> Add a status beacon above Generator that alternates green and red every second while the game is running. Preserve PreservedTree.
