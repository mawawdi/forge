# ForgeRuntime

An optional Forge-owned MIT source bundle, ABI `forge-runtime@1`. There are no third-party dependencies or creator-time downloads. `runtime.lock.json` binds the license, each regular Luau source file and the complete bundle. The loader verifies bytes before producing compiler material. Changing source requires a reviewed lock update.

`loadForgeRuntimeBundle()` loads the bundle. `createForgeRuntimeRecipe(bundle)` returns its trusted definition, expander and locked source lookup. The definition ABI includes the bundle hash. Selecting the recipe with `{}` configuration installs ModuleScripts under `ReplicatedStorage/Packages/ForgeRuntime`. Existing folders retain their observed identities; existing modules are reused only with exact observed source hashes and byte counts. Conflicting modules are rejected. Neither loading nor expansion executes game source.

`forgeRuntimeSourcePackage` offers the same ordinary locked source files when the caller already has an exact parent inventory. `emitStaticModuleImport` and `emitScopedBootstrap` produce optional ordinary Luau source. A utility package needs no entrypoint or runtime. The bootstrap assumes each explicitly named export accepts a Scope and optionally returns one cleanup function; the caller owns the corresponding source contract and native integration checks.

| Module         | Contract                                                                                                                                                                                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Scope`        | `new`, `Defer`, `Guard`, `Close`. Closing increments generation before any cleanup, rejects later registrations, disposes in reverse registration order and aggregates errors. Cleanup callbacks must not yield. Unregistering releases a cleanup without invoking it.                                          |
| `Event`        | `new`, `Connect`, `Fire`, `Destroy`. Reentrant emissions drain FIFO. Each emission snapshots listeners; delivery rechecks connection and optional Scope generation. Listener failures and yields are isolated. Errors from reentrant emissions are reported by the outermost drain.                             |
| `Task`         | `start(scope, work, options)`. Optional deadline, completion callback and scheduler. Cancellation invalidates the token before cancelling scheduled work. `token:Guard` and completion delivery suppress stale effects. Completion callbacks must not yield. No Promise implementation is bundled.              |
| `StateMachine` | `new(graph)`, `Send`, `GetState`, `Snapshot`, `Destroy`. Arbitrary string states and cyclic edges; ordered synchronous guards choose the first permitted transition. Invalid or failing guards and reentrant sends reject without a logical state commit. No game lifecycle or effect vocabulary is prescribed. |

These primitives provide lifecycle conventions, not a security boundary. Task cancellation cannot undo work already performed, and guarded callbacks are checked at entry rather than after arbitrary yields. Scope owns only registered cleanups. StateMachine replay concerns logical transitions; it cannot roll back external effects inside a guard. Roblox scheduling, Instances and integration behavior require native evidence.

The fixed repository runner `luau test/runtime-modules.luau` exercises the real sources with a deterministic virtual scheduler. The Node regression invokes it with a host wall-clock and output bound. It accepts no candidate paths or source. This is not a general untrusted-code worker, an OS sandbox, a descendant-process bound or a total-memory bound. Parse/type checks do not establish native behavior or prove the absence of all dynamic typing gaps.
